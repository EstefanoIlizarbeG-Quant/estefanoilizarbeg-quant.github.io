# Estéfano Marcelo Ilizarbe Gonzales

Web personal académica con proyectos de econometría, apuntes matemáticos, formación y experiencia.

Sitio: https://estefanoilizarbeg-quant.github.io/

## Contenido

- `index.html`: presentación, proyecto ENAHO y catálogo de nueve apuntes.
- `cv.html`: CV público con una vista preparada para imprimir o guardar como PDF desde el navegador.
- `assets/`: estilos, interacciones y favicon.
- `robots.txt` y `sitemap.xml`: configuración de descubrimiento del sitio.
- `.nojekyll`: publicación directa de los archivos estáticos.

## Publicación en GitHub Pages

En **Settings → Pages**, seleccionar **Deploy from a branch**, rama **main**, carpeta **/(root)**. El repositorio del sitio de usuario se llama `estefanoilizarbeg-quant.github.io`.

El sitio funciona sin compilación, dependencias externas ni servicios de servidor. El catálogo es HTML y permanece disponible cuando JavaScript está desactivado. JavaScript añade búsqueda, filtros de los apuntes y navegación móvil.

## Actualizaciones

Los archivos `.tex` se enlazan al repositorio [matematicas-aplicadas](https://github.com/EstefanoIlizarbeG-Quant/matematicas-aplicadas). El proyecto econométrico se enlaza a [tic-ingresos-laborales-enaho](https://github.com/EstefanoIlizarbeG-Quant/tic-ingresos-laborales-enaho).

Para configurar Google Search Console, verificar la propiedad del sitio una vez publicado y agregar el archivo o la etiqueta de verificación que indique Google. Después, enviar `sitemap.xml` e inspeccionar la página principal para solicitar su indexación.
